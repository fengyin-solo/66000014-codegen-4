# solo-6600001 - 在线协作白板应用

## 项目简介
构建一个在线协作白板应用，支持多人实时绘图、便签、形状工具，具备画布缩放/平移、图层管理、实时光标显示、导出为PNG/PDF功能，使用WebSocket实现多人同步

## 技术栈
- **前端**: React + TypeScript + Canvas API + Zustand
- **后端**: Node.js + Express + Socket.io
- **数据库**: MongoDB

## 快速开始

### 服务端
```bash
cd server
npm install
npm run dev
```

### 客户端
```bash
cd client
npm install
npm run dev
```

## 功能特性
- 多人实时协作绘图
- 画笔、矩形、圆形、直线、文本工具
- 便签功能
- 图层管理（新建、可见性、锁定）
- 实时光标显示
- 画布缩放/平移
- WebSocket实时同步
- **成员权限中心**：画板创建者可邀请成员，分别授予「查看 / 评论 / 编辑」能力
  - 查看者：只读浏览，不能评论或改动任何已有内容
  - 评论者：可浏览并发表评论，不能修改画板内容
  - 编辑者：可绘图、添加便签、管理图层
  - 邀请幂等：未完成邀请、重复邀请都不会产生多份成员记录
  - 移出成员后其记录标记为 `removed`，再次进入看到只读说明；重新邀请复用原记录
  - 权限变更通过 WebSocket 实时下发，立即改变画板的打开方式与协作连接
  - 旧画板（仅有 collaborators 字段）自动迁移为可编辑成员，原有协作不受影响
